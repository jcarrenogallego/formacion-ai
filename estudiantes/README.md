# Entregas de estudiantes

Cada participante debe crear una carpeta cuyo nombre coincida exactamente con su usuario de GitHub:

```text
estudiantes/<github-login>/
```

La carpeta [`josecarreno`](josecarreno/) es únicamente un ejemplo de organización. No guardes entregas dentro de ella: copia su estructura en una carpeta nueva con tu propio usuario.

```text
estudiantes/
├── josecarreno/       ← ejemplo
├── jperez/            ← estudiante @jperez
└── mdiaz/             ← estudiante @mdiaz
```

La validación del repositorio compara el autor de la pull request con el segundo segmento de la ruta. Por ejemplo, `@jperez` solo puede modificar archivos dentro de `estudiantes/jperez/`.

Consulta [CONTRIBUTING.md](../CONTRIBUTING.md) y las instrucciones del ejercicio de cada sesión antes de preparar una entrega.
