# Proyecto de la entrega

En la entrega real, sustituye este archivo por una copia de:

```text
sesiones/sesion-05/material/proyecto-codex-dotnet/
```

Después:

1. ejecuta `./scripts/validate-session-05.ps1 -Baseline`;
2. configura el identificador de Engram;
3. instala BMad Method con `./scripts/install-bmad.ps1`;
4. reinicia Codex;
5. completa el ejercicio sin modificar archivos fuera de tu carpeta personal.

No copies `bin/`, `obj/`, `node_modules/`, bases locales, caches, logs ni credenciales.
