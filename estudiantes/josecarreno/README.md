# Ejemplo de carpeta personal

Esta carpeta muestra cómo organizar las entregas de las sesiones publicadas.

Para utilizarla como referencia:

1. Crea `estudiantes/<github-login>/` usando tu usuario real de GitHub.
2. Reproduce dentro las carpetas de las sesiones que debas entregar.
3. Sustituye los documentos de ejemplo por tu trabajo.
4. No modifiques `estudiantes/josecarreno/` ni la carpeta de otra persona.

```text
estudiantes/<github-login>/
├── README.md
├── sesion-01/
│   └── ejercicio-01/
├── sesion-02/
│   └── ejercicio-01/
├── sesion-03/
│   └── ejercicio-01/
├── sesion-04/
│   └── ejercicio-01/
└── sesion-05/
    └── ejercicio-01/
```

El `README.md` personal puede incluir tu nombre, usuario de GitHub y un índice de tus entregas.
