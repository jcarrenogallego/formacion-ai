# Ejemplo de entrega - Sesión 4

La entrega real debe seguir las instrucciones de [`sesiones/sesion-04/ejercicio`](../../../../sesiones/sesion-04/ejercicio/).

```text
ejercicio-01/
├── README.md
├── PROMPTS.md
├── MEMORY.md
├── IMPACT_ANALYSIS.md
└── proyecto/
    ├── .codex/config.toml
    ├── context/PROJECT_CONTEXT.md
    ├── frontend/
    ├── backend/
    ├── openspec/
    └── scripts/
```

Copia el proyecto desde `sesiones/sesion-04/material/proyecto-codex-dotnet/` y reemplaza el identificador de Engram por uno que incluya tu usuario de GitHub.
