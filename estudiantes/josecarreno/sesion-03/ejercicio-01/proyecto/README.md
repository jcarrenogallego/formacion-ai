# Proyecto de la sesión 3

Copia aquí `sesiones/sesion-03/material/proyecto-codex-dotnet/` y evolúcionalo mediante el proceso SDD.

Además del código, la entrega real debe contener:

```text
.agents/skills/
openspec/
├── config.yaml
├── specs/
└── changes/archive/
```

OpenSpec genera y mantiene estos artefactos durante `propose`, `apply` y `archive`; no deben sustituirse por documentos creados manualmente fuera del flujo.
