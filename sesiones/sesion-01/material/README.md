# Material para el clasificador de imágenes

Este conjunto contiene 50 imágenes de perros y 50 imágenes de gatos para entrenar un clasificador en [Teachable Machine](https://teachablemachine.withgoogle.com/).

```text
material/
├── perros/
│   ├── perro-001.jpg
│   └── 1-a-fuentes.csv
└── gatos/
    ├── gato-001.jpg
    └── 1-a-fuentes.csv
```

Los archivos `1-a-fuentes.csv` relacionan cada imagen con su ubicación dentro del dataset original.

## Procedencia y licencia

Las imágenes proceden del dataset [Cats and Dogs Image Classification](https://www.kaggle.com/datasets/samuelcortinhas/cats-and-dogs-image-classification), publicado en Kaggle con licencia **CC0: Public Domain**.

El material se utiliza con fines formativos para practicar la creación y evaluación de un modelo sencillo de clasificación de imágenes.
