# Instrucciones del proyecto

## Código

- Utiliza JavaScript sin dependencias externas.
- Conserva los nombres y las exportaciones públicas existentes.
- No modifiques los arrays ni los objetos recibidos como argumentos.
- Mantén separadas la lógica de cálculo y la presentación de resultados.
- Evita duplicar recorridos cuando una única operación resulte clara.

## Verificación

- Ejecuta `npm test` después de modificar el código.
- Conserva todas las pruebas existentes.
- Añade pruebas para cualquier caso límite que descubras.
- No des por terminada una tarea si las pruebas fallan.
